WarmHouse MVP

This is the parallel MVP deployment for the smart home platform.

The original monolith remains available on warmhouse.yerlan-amantaiuly.kz.

Deployment Goal

The MVP site is deployed independently so the legacy As-Is stand is preserved and can be compared with the new target solution.

Planned MVP Capabilities

  • Device registry service for onboarding devices.
  • Telemetry service for fresh readings and history.
  • Independent deployment flow for future microservices.
